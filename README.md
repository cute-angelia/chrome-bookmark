# 截屏书签 · CutBookmark 2.0

> 现代化的智能截屏与书签管理 Chrome 扩展，基于 **Vite 5 + Vue 3 + Tailwind CSS + Lucide Icons + Chrome Extension MV3** 全新重构升级。
> 本版本已正式落地方案 **三栏管理工作台 (Workspace)**，为重度书签收集与研究用户打造结构清晰、高产出的视觉化整理中心。

### 1. 栏目 1：侧栏导航与控制中心 (Sidebar)
- **快捷智能视图**：全部书签、⭐️ 已置顶、📸 包含视觉快照、🕒 最近 7 天添加、🔥 高频访问（>20次）。
- **分类文件夹树**：各分类实时书签计数统计，支持新建分类、删除分类与分类快速联动筛选。
- **标签云系统**：全库标签自动去重与频次聚合，点击标签秒级多维过滤。
- **数据备份与恢复**：支持一键导出整库为标准 JSON 文件，或从 JSON 文件恢复。

### 2. 栏目 2：书签主列表流 (Master List)
- **全局极速检索**：支持对书签标题、访问链接、主域名、关联标签及个人研读笔记进行实时模糊匹配。
- **多维灵活排序**：支持最新添加、最早添加、高频访问降序、标题拼音 A-Z 排序。
- **双模展现形态**：随时一键切换「图文卡片流 (Card Feed)」与「紧凑表格行 (Compact Row)」。
- **批量整理模式**：支持一键全选或多选、批量勾选、批量删除。

### 3. 栏目 3：右侧详情检视器 (Inspector Detail)
- **高清视觉快照**：高清晰度展示捕获的网页快照，支持点击进入沉浸式全屏放大灯箱，支持随时更新截屏。
- **属性即时编辑**：标题在线修改即改即存，快捷下拉调整所属分类。
- **标签动态维护**：已有标签一键移除，支持回车快速新增自定义标签。
- **研读笔记与摘要**：多行个人备忘录与分析卡片，失焦自动持久化。
- **访问统计累加**：每次点击外链访问原网页自动递增访问计数。

### 4. 浏览器快捷捕获弹窗 (Popup)
- 在任意网页点击扩展图标呼出精致轻量弹窗，自动读取当前页标题与 URL，一键截取当前视口高清快照、打标签并秒级保存。

## 🛠 本地开发与体验

### 1. 启动 Web 本地开发服务
```bash
npm run dev
```
打开浏览器访问：[http://localhost:5173/](http://localhost:5173/)
- 体验完整的三栏工作台操作、搜索、过滤、新建、编辑与全屏灯箱。
- 页面铺满浏览器视口，右上角仅用呼吸灯表示远程连接状态，点击灯打开连接设置。
- Web 模式不能访问 Chrome 原生书签；原生书签需在扩展页面中查看。远程服务需要有效登录，Web 模式还需要服务允许当前来源的跨域请求。
- 工作台读取 Chrome 书签目录树和远程书签，并标记来源，不再自动填充示例数据。远程请求先读取第一页，与本地缓存按远程 ID 对比：整页都已存在就停止，否则继续下一页，直到遇到整页已存在或末页。局部刷新保留未请求页面的缓存，首次没有缓存时逐页建立缓存。Chrome 目录保留层级，原生变更自动刷新，远程数据在页面聚焦和每分钟做上述增量检查。
- 刷新截图会临时打开书签网页，加载完成后生成可视区域的真实 PNG，保存后返回工作台；失败保留原图，不使用随机图片兜底。仅 Chrome 扩展支持截图。
- 书签、目录、截图、远程缓存和工作台注解保存在 IndexedDB（`cutbookmark`），不迁移旧数据，并定向删除本项目旧 localStorage 数据键；网页连接配置也存 IndexedDB，扩展连接配置仍使用 Chrome 配置存储。
- 页面删除会同步删除对应的 Chrome 本机书签；整理目录调用 Chrome 原生移动接口，没有本机副本时会创建。遇到多个同网址副本先选择具体条目，不直接批量操作。
- 来源书签的标题为只读；扩展中可选择 Chrome 目录进行整理，小屏下可横向滚动浏览三栏工作台。
- 数据层回归测试：`npm test`。

### 2. 构建与安装 Chrome 扩展
```bash
npm run build
```
构建产物输出至 `dist/` 目录：
1. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
2. 开启右上角 **“开发者模式”** (Developer mode)。
3. 点击左上角 **“加载已解压的扩展程序”** (Load unpacked)。
4. 选择当前项目的 `dist/` 目录即可安装加载！
